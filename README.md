## 🌟 Key Features

- **🌐 Dynamic Tri-Lingual i18n Engine:** Seamless runtime switching between **German (DE)**, **English (EN)**, and **Arabic (AR)** via localized `data-i18n` dictionaries with automatic Right-to-Left (RTL) layout transformation and tailored typography.
- **🌗 Adaptive Dual Theme Engine:** High-contrast Cyberpunk Obsidian Dark Mode and crisp Clean Light Mode powered by CSS custom properties and instant persistent `localStorage`.
- **⚡ Zero-Dependency Performance:** Pure Vanilla JavaScript and CSS with zero heavy bundle overhead, ensuring lightning-fast load times, near-instant First Contentful Paint (FCP), and flawless 60 FPS transitions.
- **📄 Interactive Curriculum Vitae Hub:** Integrated PDF preview modals and instant download triggers for curated technical CVs in both German and English.
- **📱 Fluid Mobile-First Responsive Design:** Mobile drawer navigation, active scrollspy navbar highlighting, and smooth touch-optimized gestures across all viewports.
- **🛡️ Clean Privacy-Compliant Architecture:** Static edge deployment with zero invasive trackers, GDPR-friendly structure, and accessible semantic HTML5.

## 🚀 Local Development & Setup

### Prerequisites

No complex toolchains or package managers are required. You only need a modern web browser.

### Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Ploger1979/portfolio.git
   cd portfolio
   ```

2. **Serve the project:**
   You can open `index.html` directly in any web browser, or launch a local development server:
   ```bash
   # Using VS Code Live Server extension, OR:
   npx serve .
   ```

3. **Navigate:**
   - Developer Portfolio: [http://localhost:3000/index.html](http://localhost:3000/index.html)
   - Client Business Portal: [http://localhost:3000/clients.html](http://localhost:3000/clients.html)
